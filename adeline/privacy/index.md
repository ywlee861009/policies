# 아델린의 작은 식탁 개인정보 처리방침

**검토용 초안 — 게시 전 확인 필요**

현재 구현을 기준으로 작성했습니다. 표시된 운영자 정보, 연락처, 이메일 처리·국외 이전, 보유기간과 시행일을 확정한 후 게시하세요. 광고·결제 도입에는 방침 갱신과 실제 개인정보 선택 절차가 필요합니다.

## 한눈에 보기

- 진행·설정과 자동 백업은 기기에 저장됩니다.

- 현재 광고, 인앱결제, 클라우드 저장 및 분석·오류 보고 서비스는 없습니다.

- 문의 이메일과 정책 페이지 접속 정보는 별도로 처리될 수 있습니다.

<a id="scope"></a>

## 1. 적용 범위와 운영자

이 처리방침은 케로스튜디오가 제공하는 「아델린의 작은 식탁」(이하 “게임”)과 게임에 관한 개인정보 문의에 적용됩니다. 현재 확인된 게임 버전은 기기 안에서 진행을 저장하는 방식이며 회원가입, 운영자의 서버 저장, 클라우드 동기화, 광고, 인앱결제, 이용 분석 및 오류 보고 서비스가 포함되어 있지 않습니다.

운영자의 법적 명칭: **[실명 또는 법인명 확인]** (서비스 표시명: 케로스튜디오). 소재지: **[공개 가능한 업무용 주소 입력]**. 개인정보 관련 연락처는 [13항](#contact)에 안내합니다.

앱 마켓, 기기 운영체제, 이용자가 사용하는 백업 서비스 및 외부 웹사이트는 각 서비스의 방침에 따라 별도로 정보를 처리할 수 있습니다. 게임을 웹으로 배포하는 경우 게임 호스팅 서비스의 접속 정보 처리도 출시 전에 이 방침에 추가합니다.

## 2. 현재 처리하는 정보, 목적과 근거

| 구분 | 정보 항목 | 목적과 처리 방식 |
| --- | --- | --- |
| 기기 내 저장 | 보드, 코인, 주문 및 합성 횟수, 성장, 가게 수리, 축제, 도감, 이야기·추억, 소리 설정, 최근 자동 백업 | 진행 저장·복구와 이용자가 선택한 설정 적용. 브라우저의 로컬 저장소에 보관하며 운영자에게 전송하지 않습니다. |
| 백업 내보내기·가져오기 | 이용자가 저장하거나 선택한 게임 진행 JSON 파일 | 이용자가 요청한 백업·복구. 선택한 파일은 기기에서 읽으며 운영자 서버로 업로드하지 않습니다. |
| 이메일 문의 시 | 발신 이메일 주소, 이용자가 적은 이름·문의 내용·첨부파일 및 최소한의 확인 정보 | 문의 답변, 문제 해결, 개인정보 권리 행사 처리. 이용자가 이메일을 보낼 때에만 운영자가 받습니다. |
| 이 방침 페이지 접속 시 | GitHub Pages가 보안 목적으로 기록하는 IP 주소 등 접속 정보 | 정책 페이지 제공 및 호스팅 보안. 게임 진행 데이터와 별개입니다. |

기기 내 저장은 이용자가 요청한 게임 기능 제공에 사용하며, 기기 내 진행 정보를 운영자가 이용자 식별 정보와 결합하지 않습니다. 이메일 문의 처리에 필요한 정보는 「개인정보 보호법」 제15조 제1항 제4호에 따른 계약 이행·요청 처리 등 실제 적용 가능한 근거로 처리합니다. 별도 동의가 필요한 추가 정보는 목적, 항목, 보유기간과 거부 시 영향을 안내하고 동의를 받습니다. 법정 의무 이행이 필요한 경우에는 해당 법적 근거에 따라 최소한의 정보를 처리합니다.

문의하지 않아도 게임을 이용할 수 있습니다. 다만 회신 주소나 문제 설명을 제공하지 않으면 해당 문의를 처리하기 어려울 수 있습니다. 주민등록번호, 카드번호, 계정 비밀번호, 건강 정보나 불필요한 타인의 정보를 보내지 마세요. 현재 게임은 광고 식별자, 정확한 위치, 연락처, 사진, 마이크 정보 또는 생체정보를 요구하거나 수집하지 않습니다.

## 3. 보유기간과 법정 보존

| 정보 | 보유기간 또는 기준 |
| --- | --- |
| 기기 내 진행·자동 백업 | 이용자가 해당 게임의 브라우저 사이트 데이터를 삭제할 때까지. 내보낸 파일은 이용자가 직접 삭제할 때까지 보관됩니다. |
| 문의 이메일·첨부자료 | **[문의 종결 후 보유기간 확정]** — 처리 목적이 끝난 정보는 정해진 기간에 따라 삭제합니다. 분쟁·법정 의무가 있는 경우 필요한 부분만 별도 보존합니다. |
| GitHub Pages 접속 기록 | GitHub가 자체 보안 목적과 개인정보 방침에 따라 관리합니다. 운영자가 이 파일만으로 보유기간을 지정하거나 해당 기록을 직접 삭제할 수는 없습니다. |

현재 게임에는 구매 기록이 없습니다. 향후 인앱결제 도입 시 운영자에게 법정 거래기록 보존 의무가 적용되면, 계약·청약철회 기록 및 대금결제·재화 공급 기록은 각각 5년, 소비자 불만·분쟁처리 기록은 3년 등 해당 법령의 기간 동안 필요한 항목만 보존합니다. 이는 현재 모든 게임 데이터나 일반 문의를 일괄 장기 보관한다는 뜻이 아닙니다. 적용 법령, 대상 항목과 기간은 도입 시 확정해 공개합니다.

## 4. 삭제 절차와 방법

- **기기 내 데이터 전체 삭제:** 브라우저 설정에서 게임 주소의 사이트 데이터·로컬 저장소를 삭제하세요. 현재 저장에는 진행과 최근 자동 백업이 함께 포함됩니다.

- **새 게임 시작과 완전 삭제는 다릅니다:** 게임의 “처음부터 다시 시작하기”는 진행을 초기화하면서 이전 진행을 자동 백업에 남길 수 있습니다. 완전 삭제하려면 사이트 데이터도 삭제해야 합니다.

- **내보낸 백업:** 기기의 다운로드 폴더, 파일 앱 및 이용자가 복사한 저장 위치에서 직접 삭제하세요. 브라우저 데이터 삭제만으로 내보낸 파일이 삭제되지는 않습니다.

- **운영자가 보유한 문의:** 보유기간 종료 또는 적법한 삭제 요청 후 지체 없이 삭제합니다. 법정 보존이 필요한 부분은 다른 목적의 처리와 분리하고, 그 근거와 기간을 안내합니다. 전자자료는 복구·재생이 어렵도록 삭제하고 종이자료가 있으면 파쇄합니다.

운영자는 이용자 기기의 저장소를 원격으로 열람하거나 삭제할 수 없습니다. 향후 네이티브 앱으로 출시할 경우 삭제·재설치·운영체제 백업 후 복원되는 범위를 실제 동작에 맞춰 추가 안내합니다.

## 5. 제3자 제공과 처리위탁

현재 게임 진행 정보를 광고회사에 제공하거나 판매하지 않습니다. 기기에서만 처리되는 진행 정보에는 운영자의 외부 처리위탁이 없습니다. 문의를 보내면 메일의 전달·저장과 답변 과정에서 이메일 서비스 제공자가 관여합니다. 정책 페이지 호스팅에는 GitHub Pages를 사용합니다.

| 서비스 | 업무와 정보 | 관련 방침 |
| --- | --- | --- |
| Google 이메일 서비스 | 문의 이메일·첨부파일의 전달·보관. 정확한 계약상 법인 및 처리위탁 여부는 **[게시 전 확인]** | [Google Privacy Policy](https://policies.google.com/privacy) |
| GitHub Pages | 정책 페이지 호스팅 및 서비스 보안. IP 주소 등의 접속 기록 | [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) |

운영자는 정보를 처리하도록 위탁하는 경우 관련 법령에 따른 계약, 목적 외 처리 제한 및 필요한 감독을 적용합니다. 각 제공자가 자체 목적의 개인정보처리자에 해당하는 범위에서는 해당 제공자의 방침도 적용됩니다. 법령상 의무, 적법한 기관 요청 또는 이용자의 별도 동의가 있는 경우에만 필요한 범위의 추가 제공을 검토합니다. “자체 서버가 없다”는 사실이 운영자가 관여한 처리에 대한 책임을 없애지는 않습니다.

## 6. 국외 이전

게임 진행·자동 백업은 현재 운영자를 통해 국외로 전송되지 않습니다. 다만 Google 이메일 서비스로 문의를 보내거나 GitHub Pages의 이 페이지에 접속하면 해당 서비스의 해외 처리·보관이 관련될 수 있습니다.

개인정보 보호법상 국외 이전에 해당하는 처리에는 제28조의8에서 허용하는 실제 근거를 적용합니다. 계약 이행에 필요한 처리위탁·보관이라는 사유는 광고나 선택적 분석 등 모든 처리에 일괄 적용하지 않습니다. 동의가 필요한 이전에는 이전 전에 별도 동의를 받습니다.

| 확인·공개 항목 | 이메일 문의 관련 이전 |
| --- | --- |
| 이전받는 자와 연락처 | **[계약상 Google 법인 및 개인정보 문의 연락처 확정]** |
| 이전 국가 | **[실제 처리·보관 국가 확인 후 국가명 기재]** |
| 이전 항목·목적 | 발신 주소, 문의 내용, 이용자가 제공한 이름·첨부파일 / 문의 전달·보관·응답 |
| 시기·방법 | 이용자가 메일을 보내고 운영자가 문의를 처리하는 동안 이메일 서비스의 통신·보관 방식으로 처리 |
| 보유기간 | **[운영자의 문의 보유기간 및 제공자 보유 기준 확정]** |
| 법적 근거·거부 방법·영향 | **[이전 근거와 유효한 거부 절차 확정]** / 이메일 문의를 보내지 않아도 기본 게임은 이용할 수 있으나 해당 이메일 문의는 처리할 수 없습니다. |

호스팅 제공자의 자체 접속 기록 처리는 5항의 GitHub 방침에서 확인할 수 있습니다. 운영자가 위탁·제공하는 이전에 해당하는지는 실제 계약·처리 구조에 따라 확인하여, 해당하면 수신 법인·국가·항목·시기·방법·목적·보유기간·거부 절차를 별도 공개합니다.

## 7. 향후 광고 도입 시 적용할 원칙

**현재 버전에는 광고가 없습니다.** 광고 또는 보상형 광고를 도입하면 실제 수집을 시작하기 전에 이 방침을 갱신하고, 필요한 동의 및 거부 절차를 제공합니다. 이 항목은 아직 선택되지 않은 광고회사가 현재 정보를 수집한다는 고지가 아닙니다.

- 광고 식별자, IP 주소에 따른 대략적 위치, 기기·앱 정보, 광고 노출·클릭·시청 기록 및 개인정보 선택 기록 등 실제 수집되는 항목과 목적을 공개합니다.

- 광고 공급자와 중개에 참여하는 회사, 각 회사의 역할·정보 수신 범위, 보유기간 및 국외 이전 내역을 공개합니다. SDK 실행·광고 요청 단계에서 수집된다면 그 시점도 안내합니다.

- 맞춤형 광고 및 선택적 추적에 필요한 동의를 별도로 받고, 광고 개인정보 설정에서 동의를 철회하거나 관련 처리를 거부할 수 있게 합니다. 광고 ID 삭제·재설정은 앱의 동의 철회나 법정 판매·공유 거부를 대신하지 않습니다.

- EEA에서는 비필수 기기 정보 접근·저장에 요구되는 사전 동의를 확인합니다. 비맞춤형 광고에도 동의가 필요한 기기 식별자 처리가 포함될 수 있습니다.

- 미국에서 광고 목적의 전달이 법상 “판매” 또는 “공유”에 해당하면 적용되는 거부권과 Global Privacy Control 등 신호 처리 방법을 제공합니다.

- 동의 거부만으로 기본 게임 이용을 차단하지 않습니다. 적법한 광고 제공이 불가능하면 광고·광고 보상이 제공되지 않을 수 있으며, 이를 선택 전에 안내합니다. 아동·청소년에 대해서는 별도의 보호 기준을 적용합니다.

## 8. 향후 인앱결제 도입 시 적용할 원칙

**현재 버전에는 인앱결제가 없습니다.** 도입하면 구매 전에 결제 제공자와 정보 처리 범위를 안내합니다. 앱 마켓 결제를 사용하는 경우 카드번호·계좌 등 결제수단 정보는 해당 결제 제공자가 처리하며, 운영자가 받는 구매 확인 정보와 구분해 고지합니다.

운영자가 처리하게 되는 상품 ID, 거래 ID·구매 토큰, 구매·환불 시각 및 상태, 구매 권한 등의 항목은 실제 구현에 맞춰 명시합니다. 그 정보는 구매 확인, 콘텐츠 제공·복원, 환불 지원, 부정 구매 방지 및 법정 의무 이행에 필요한 범위에서 사용하며 광고 동의와 결합하지 않습니다. 실제 보유기간, 제공·위탁 관계, 국외 이전 및 삭제 후 유지되는 법정 기록을 함께 공개합니다.
