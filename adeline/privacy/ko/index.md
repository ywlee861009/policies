## 2. 선택형 보상 테스트 광고

재료 에너지가 소진되면 이용자는 보상형 테스트 광고를 요청할 수 있습니다. 이때 Google Mobile Ads Next-Gen SDK가 초기화되어 광고를 불러옵니다. SDK는 광고 제공, 이용 측정 및 부정 이용 방지를 위해 다음 정보를 Google로 전송할 수 있습니다. 광고 요청 시점부터 처리될 수 있으며 시청 완료는 전송의 조건이 아닙니다.

- IP 주소 및 이로부터 추정한 대략적인 지역
- 앱 실행, 탭, 광고 영상 조회 등 상호작용 정보
- 앱과 SDK의 성능 및 진단 정보
- 앱 세트 ID 등 기기·앱 관련 식별자와 해당되는 경우 기기에 로그인한 계정과 관련된 기타 식별자

앱의 Android 매니페스트에는 Android 광고 ID(`AD_ID`) 권한을 제외하도록 설정되어 있습니다. SDK 데이터는 전송 중 TLS로 암호화됩니다. 광고를 요청하지 않고도 기본 게임을 이용할 수 있습니다. [Google 광고 SDK 데이터 처리 안내](https://developers.google.com/admob/android/next-gen/privacy/play-data-disclosure?hl=ko) · [Google의 파트너 앱 데이터 사용 안내](https://policies.google.com/technologies/partner-sites?hl=ko)

## 3. 외부 서비스와 국외 처리

Google은 광고를 요청할 때 광고 SDK 데이터를, 이메일 문의가 접수되면 Gmail을 통해 해당 문의 정보를 처리합니다. GitHub는 정책 페이지의 방문 정보와 보안 로그를 처리합니다. 이 정보는 미국 등 각 제공자가 시스템을 운영하는 국가에서 처리될 수 있습니다. SDK 데이터와 정책 페이지 접속은 암호화된 연결로 전송됩니다. 광고를 선택하지 않거나 이메일을 보내지 않으면 해당 기능에 따른 전송을 피할 수 있습니다. 서비스 제공자의 보관·삭제 기준과 연락 방법은 각 방침에서 확인할 수 있습니다. ## 4. 보유, 삭제 및 보호

- **기기 내 기록과 내부 자동 백업**은 앱 전용 저장공간에 보관됩니다. 전체를 지우려면 Android **설정 → 앱 → 아델린의 작은 가게 → 저장공간 → 데이터 삭제**를 이용하거나 앱을 삭제하세요. 게임 내에서 새로 시작하면 이전 진행이 내부 백업에 남을 수 있습니다. 앱의 Android 자동 클라우드 백업은 비활성화되어 있습니다.
- **직접 저장한 백업 파일**은 저장한 위치에서 별도로 삭제해야 합니다. 클라우드에 저장했다면 해당 서비스에서 파일을 관리할 수 있습니다.
- **문의 이메일과 첨부 자료**는 답변과 요청 처리에 필요한 기간 동안 보관한 뒤 메일함에서 삭제합니다. 법적 보존 의무나 진행 중인 분쟁이 있으면 필요한 범위에서 해당 기간 동안 보관합니다.
- **이미 외부 서비스에 전송된 정보**에는 해당 서비스의 보관·삭제 기준이 적용됩니다. 앱 데이터를 삭제하면 기기에 저장된 데이터가 지워집니다.

## 5. 이용자의 권리

이용자나 적법한 대리인은 아래 이메일로 개인정보의 열람, 정정, 삭제, 처리정지 및 적용 법령이 보장하는 동의 철회, 처리에 대한 이의 제기, 데이터 이동 등을 요청할 수 있습니다. 운영자는 요청 확인에 필요한 최소한의 정보만 요청합니다. 아동의 정보에 관한 보호자 문의도 같은 이메일로 받습니다.

유럽경제지역(EEA)이나 영국의 개인정보 보호법이 적용될 경우, 운영자의 지원 처리 근거는 요청 이행에 필요한 계약의 이행 또는 문의 응답을 위한 정당한 이익이고, 법적으로 필요한 보존은 법적 의무에 근거합니다. 별도 동의가 필요한 처리에는 해당 동의 요건이 적용되며, 동의를 철회할 수 있습니다. 이용자는 관할 개인정보 감독기관에 민원을 제기할 수 있습니다. 한국에서는 개인정보침해신고센터 또는 개인정보분쟁조정위원회에 상담이나 피해 구제를 요청할 수 있습니다.
