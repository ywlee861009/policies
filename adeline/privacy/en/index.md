# Adeline's Little Shop Privacy Policy

Kero Studio, operated by Youngwoo Lee, provides **Adeline's Little Shop** (아델린의 작은 가게, Android app ID `com.kero.adeline`). This policy describes how information is handled when you play the game or contact us.

- Published and effective November 6, 2026.
- For privacy questions and requests, contact Youngwoo Lee at [ywlee861009@gmail.com](mailto:ywlee861009@gmail.com).

<a id="data"></a>

## 1. Information and purposes

| Feature | Information and purpose | Where it is processed |
|---|---|---|
| Game saves | The board, orders, coins, energy, renovation and story progress, preferences, internal automatic backup, and ad-reward records used to prevent duplicate rewards are stored so the game can save and restore them. | Private app storage on your device |
| Backup files | The game saves progress to a JSON file you choose or reads the file you select to restore it. | The game handles the file on your device and saves it to the location you choose. |
| Optional rewarded test ads | Google's SDK may process the data listed in section 2 to request and display test ads, measure use, and prevent fraud. | Google's advertising service |
| Email support | We receive the email address, message, and attachments you send us so we can reply or handle your request. | Kero Studio's Gmail support inbox |
| Policy page visits | GitHub Pages logs visitor IP addresses for site hosting and security. | GitHub Pages |

You can play without registering for a game account. The game keeps progress and its internal automatic backup on your device and sends neither to our servers. The app has no in-app purchases, separate analytics or crash-reporting SDK run by us, or server sync. If you save a file to cloud storage yourself or use Google Play or another external service, the provider's privacy policy may apply to its handling of information.

## 2. Optional rewarded test ads

You can request a rewarded test ad when you run out of ingredient energy. The Google Mobile Ads Next-Gen SDK initializes and loads the ad when you make that choice. It may send the following information to Google to provide ads, measure use, and prevent fraud. Processing can begin when the ad is requested, even if you do not finish watching.

- IP address and approximate area inferred from it
- Interactions such as app launches, taps, and ad video views
- App and SDK performance and diagnostic information
- App set ID and other device or app identifiers, and identifiers associated with signed-in device accounts where applicable

The app's Android manifest is configured to exclude the Android advertising ID (`AD_ID`) permission. The SDK encrypts data in transit using TLS. You can play the core game without requesting ads. [Google Ads SDK data disclosure](https://developers.google.com/admob/android/next-gen/privacy/play-data-disclosure) · [How Google uses data from partner apps](https://policies.google.com/technologies/partner-sites)

## 3. External services and international processing

Google processes ad SDK data when you request an ad and handles support email through Gmail when you contact us. GitHub processes policy page visits and security logs. ## 4. Retention, deletion, and protection

- **Local saves and internal automatic backups** are kept in private app storage. To erase them, use Android **Settings → Apps → Adeline's Little Shop → Storage → Clear storage** or uninstall the app. Starting a new game can leave the previous save in the internal backup. The app disables Android's automatic cloud backup.
- **Backup files you export** must be deleted separately from wherever you saved them. If you saved a file to a cloud service, you can manage it there.
- **Support emails and attachments** are kept for as long as needed to answer and handle your request, then deleted from our mailbox. If a legal duty or an ongoing dispute requires us to keep a record, we retain the necessary information for that period.
- **Data already sent to external services** is subject to their retention and deletion rules. Clearing app data removes data stored locally by the app.
